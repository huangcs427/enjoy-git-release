相较 v1.1.4 的更新，截至 2026 年 11 月 28 日。

### 系统要求

- Mac 版需要 **macOS 13.0（Ventura）或更高版本**。macOS 12（Monterey）设备将继续保留现有版本，不再自动升级到此版本。

### 新功能

- **差异与合并支持自动换行**，可在差异视图和显示设置中切换，并在文件视图、三栏合并中沿用；折行后仍可按行滚动和选择文本。
- **SFTP 远程编辑器支持多文件与并排对比**，可同时打开多个远程文件，也可将两个远程文本文件并排对比，并在对比时直接编辑和保存当前文件。
- **SFTP 新增快速预览与更多文件操作**，支持按空格快速预览文件、在远端复制普通文件和批量移动所选项目；文件栏可按需自动跟随 SSH 终端的当前目录。
- **服务器设置支持从 SSH 配置导入**，可读取 `~/.ssh/config`，搜索并批量选取主机；包含跳板或代理命令的条目会标注当前连接限制。
- **自定义命令新增代码编辑器与跨仓库复制**，编辑命令时支持语法高亮、自动换行、缩进、切换注释和放大编辑；已配置的命令可直接复制到其他仓库复用。

### Bug 修复

- 修复 Windows 退出应用时静默安装更新可能被关机或重启中断的问题。下载完成后通过「重启并更新」安装，应用会先检查未保存的内容，再显示安装进度。
- 修复克隆取消或失败时可能误删已有空目录的问题；目标路径已被文件占用时会明确提示。
- 修复从历史恢复重命名文件时只处理一侧路径的问题。恢复会同时处理新旧路径，原位置已有未跟踪文件时会暂停并提示。
- 修复继续变基、冲突处理及后台推送时部分 Git 执行失败缺少提示的问题；切换仓库后若后台推送失败，提示中会标出出错的仓库。
- 修复写入 `.gitignore` 规则后部分文件取消跟踪失败时缺少反馈的问题，现在会列出仍受 Git 跟踪的路径。
- 修复终端聚焦时应用快捷键可能截获本应交给 Shell 的 Esc 键的问题。
- 修复三栏合并和内置终端无法读取系统剪贴板时缺少提示的问题，读取失败时会提示重新复制。
- 修复部分紧凑布局下焦点轮廓被裁切或遮挡相邻图标的问题，并避免拖拽分隔条后残留焦点引起误触。
- 修复自定义命令输出窗口及分隔条拖拽热区可能遮挡滚动条的问题。

### 功能体验

- **SSH 终端**在已建立的连接异常断开后会尝试自动重连，并保留已打开的远程文件和未保存的编辑；终端列表可停靠在左侧或右侧，支持拖拽排序和快捷键切换。
- **SFTP 浏览与传输**新增目录前进按钮，文件列表和搜索结果支持悬停查看详情；批量传输显示整体进度，可估算时一并展示剩余时间；下载完成后可定位本地文件，传输时尽量保留源文件时间戳。
- **自定义命令流水线**支持点击或拖放添加步骤、展开步骤编辑和拖拽手柄排序，删除步骤时会弹出确认提示。
- **服务器配置与部署上传**支持在多窗口同时修改服务器列表时按条合并；部署上传先写入临时文件，校验长度后再替换目标文件。
- **子模块差异**明确区分父仓库记录、暂存区和子模块实际检出的版本，标明提交是前进、回退还是分叉；支持复制各版本 SHA，并可按需检出单个子模块。
- **差异与三栏合并**优化工作区和提交差异的首屏语法高亮；三栏合并可在工具栏直接切换同步滚动、显示空白字符和折叠未变更行，并在结果栏标记尚未应用的修改。
- **应用更新**入口集成至主窗口标题栏，可直接下载新版本或重启安装。
- **网络代理与认证**收紧代理凭据匹配，应用请求和更新下载仅向符合当前代理地址与端口的服务提供已保存凭据；Git 远程认证等待上限延长至 10 分钟，为浏览器授权留出更充足的时间。
- **界面图标与组件**统一工具栏、菜单和列表的图标规范与交互样式。
- **应用运行时**升级至 Electron `45.5.0`；系统密钥库改为异步访问，并兼容读取 Linux KDE（KWallet）旧版保存的凭据。
