相较 v1.0.0 的更新，截至 2026 年 10 月 16 日。

### 破坏性变更

- **AI 提交需要重新填写 API Key**：旧版 Key 不会自动迁移。升级后请进入「偏好设置 → AI 提交」，为使用的模型重新填写 Key，保存并测试连接。
- **Git 凭据可能需要重新认证**：HTTP(S) 凭据的存储规则已调整，升级后首次拉取、推送或克隆时，可能需要重新输入账号、密码或 Token，或重新授权。
- **敏感信息存储要求提高**：系统密钥库不可用时，不再回退为明文保存 Key、密码等敏感信息。Linux 用户需确保系统密钥库可用。
- **终端默认入口变化**：未配置终端类型时，「在终端打开」默认使用内置终端。如需沿用系统终端，请在「偏好设置 → 终端与外部工具 → 终端」中切换。

### 新功能

- **WSL 仓库支持**：Windows 下可直接打开 WSL 发行版内的仓库，使用所属发行版的 Git，并适配文件读写、状态监听、搜索替换和终端。
- **仓库分组**：支持分组创建、重命名、删除、筛选和拖拽排序，记住每组上次使用的仓库。
- **分支置顶**：本地与远程分支均可置顶，并可调整置顶分支顺序。
- **工作树（Worktree）管理**：支持创建、重命名、删除、清理失效工作树和快速切换；可从远程分支创建工作树，并复用主工作树中被 Git 忽略的目录、复制忽略文件。
- **子模块管理**：支持添加、初始化、递归检出和更新子模块，以及查看子模块提交差异、丢弃变更。
- **工作区搜索与替换**：新增文件名与全文搜索，支持正则、大小写、全字匹配、单处替换和批量替换。
- **本地变更合并模式**：支持将工作区与暂存区合并为单一文件列表，提交时自动包含列表中的全部更改。
- **双栏曲线连接模式**：双栏差异视图可在补空行对齐与 IDEA 风格曲线连接之间切换。
- **内置终端**：按仓库管理多个终端标签，切换仓库或折叠面板时保留会话，支持复制粘贴、标签页右键菜单和批量关闭。
- **Windows 多终端选择**：内置终端可选择 Cmd 或 PowerShell；外部终端可选择 Windows Terminal、Cmd 或 PowerShell。
- **自定义终端**：支持保存和切换多组终端程序与启动参数配置，从 Enjoy Git 打开常用的外部终端。
- **自定义命令与部署**：支持全局或指定仓库的命令、多步骤流水线、本地命令、SSH 远程命令、SFTP 上传、远程命令失败重试及服务器连接测试。
- **命令任务中心**：集中查看运行记录与实时输出，支持终端交互输入、停止任务和点击输出中的 HTTP 链接。
- **AI 服务接入**：新增通义千问和自定义 AI 网关，兼容 OpenAI、Anthropic 两种 API 格式，支持自定义服务地址、模型 ID 和连接测试。
- **AI 生成场景扩展**：压缩提交与贮藏也可使用 AI 生成说明。
- **三栏冲突合并编辑器**：同时对照当前、传入版本并编辑最终结果，支持逐块选边、组合双方更改、自动合并无冲突内容、撤销重做和与共同祖先对比。
- **更多冲突操作**：新增 Git am 冲突的继续、跳过和中止，支持跳过当前回滚，以及在当前会话中逐步撤销冲突处理。
- **网络代理**：支持系统代理、直连和手动 HTTP/HTTPS 代理，统一用于 Git HTTPS、AI、GitHub API 和更新检查，并提供连接测试。
- **命令行工具**：可在设置中安装、卸载和检查命令行工具，通过 `enjoy-git <仓库路径>` 从终端打开仓库。
- **自动获取远端更新**：可开启后台定时获取当前仓库远端更新，默认关闭。
- **Git 检测与配置编辑**：新增当前仓库 Git 版本与路径检测，以及 `.git/config` 编辑入口。

### Bug 修复

- 修复大仓库 Git Graph 画布崩溃、分支连线断裂或重叠、图谱覆盖详情，以及滚动时与提交行错位的问题。
- 修复快速切换仓库或文件时旧数据覆盖、侧栏闪现旧内容、弹窗菜单残留，以及文件选择状态丢失的问题。
- 修复双栏差异、展开行和高亮行数设置变化后，正文与语法高亮不同步的问题。
- 修复冲突继续、中止、选边、重命名、二进制文件和 CRLF 换行处理中的问题，校验文件快照与当前 Git 操作，避免用过期结果覆盖文件。
- 修复冲突继续时提交钩子处理、Git 锁竞争及残留锁相关问题。
- 修复大量文件导致命令参数超限、特殊字符及 Windows/WSL 路径处理错误，以及旧版 Git 的拉取、遴选参数兼容问题。
- 修复外部提交后分支状态滞后、冲突完成后未推送计数不刷新，以及删除远程分支后本地跟踪引用残留的问题。
- 修复 AI 取消、文件历史加载和克隆失败收尾时的异步竞态，以及全局自定义命令跨仓库运行时状态、输出绑定错误的问题。
- 修复虚拟列表空白、滚动条异常、窄窗口内容溢出，以及 macOS 安装包内置终端启动权限问题。

### 功能体验

- **Git Graph 提交图谱**：优化布局与渲染性能，改善复杂合并、分叉和多分支汇聚时的连线，以及搜索、分支筛选结果中的图谱展示。
- **启动与大仓库性能**：优化冷启动、仓库切换、批量导入、状态加载、数千分支列表、工作区搜索和语法高亮，减少卡顿与重复刷新。
- **历史与审阅**：提交搜索支持关键字高亮和结果导航，可设置每页提交数量；改进文件历史、Blame 的长提交信息展示，新增 GitHub/Gravatar 头像来源。
- **差异对比**：改进单栏、双栏滚动、差异概览定位和上下文展开；可设置 Tab 宽度、高亮与完整展开行数上限，并补充 `.properties` 语法高亮。
- **AI 提交体验**：可设置上下文长度、额外说明、忽略文件和思考开关，展示模型返回的思考内容，并为生成请求补充文件变更摘要。
- **忽略规则操作**：可从文件菜单按路径、扩展名或任意上级目录快捷添加 `.gitignore` 规则。
- **仓库操作偏好**：可设置默认变基拉取、新建仓库的默认分支、本地更改默认处理方式，以及是否在启动时刷新所有仓库状态。
- **冲突信息展示**：展示冲突双方的来源分支、提交等详情，支持显示 diff3/zdiff3 格式中的共同祖先内容。
- **分支与标签操作**：批量创建远程跟踪分支时保留当前分支与工作区，并逐项展示结果；可从分支直接创建标签、从历史提交菜单删除标签，完善远程标签联动删除。
- **贮藏恢复**：明确区分待恢复、冲突后保留和待核对状态，可选择恢复并清理或保留贮藏，减少重复应用与误删恢复点。
- **外部程序与文件浏览**：自动识别外部程序图标和名称，改进文件树状态着色、多选统计、拖拽自动滚动和工作区干净时的快捷入口。
- **偏好设置与外观**：将原有 AI、SSH 密钥和外部程序等配置入口统一到分组设置面板，集中管理仓库、历史、差异、网络和终端工具，并支持跟随系统主题。
- **控件与退出保护**：统一表单、菜单、危险操作确认和窄窗口布局；弹窗使用 macOS 的 `⌘ + Enter`、Windows/Linux 的 `Ctrl + Enter` 快捷确认，切换仓库时确认未保存内容，退出或关闭终端时确认正在运行的任务。
- **操作反馈与更新**：完善 Git 操作进度、AI 等待与超时提示、克隆失败恢复指引、更新下载失败重试；消息在前台按有效阅读时间关闭，悬停时暂停计时。
- **macOS 安装**：同时提供 DMG 和 ZIP 安装包。
