相较 v1.1.2 的更新，截至 2026 年 11 月 20 日。

### 新功能

- **SSH 终端新增 SFTP 文件管理**，可浏览远程目录、上传和下载文件、预览与编辑文本、修改权限。支持从指定目录按名称递归搜索文件和文件夹，并可暂停和继续搜索。
- **SSH 终端新增快捷访问**，可按服务器收藏常用文件和目录、保存常用命令。快捷命令可插入终端供编辑，也可在指定目录直接运行。
- **部署上传新增文件筛选**，可用通配符或正则表达式指定要上传的文件，并单独排除文件或整个目录。排除规则优先生效。
- **命令任务中心新增运行记录搜索**。打开任务中心可统一标记未读记录为已读，命令输出中的选中文字支持右键复制。
- **深色主题新增边框设置**，可在外观设置中选择「经典」或「清晰」。

### Bug 修复

- 修复丢弃仓库改动时，父仓库的递归重置可能覆盖原本应跳过的子模块改动的问题。子模块恢复后只清理成功恢复的工作树，并保留被忽略的文件和独立的嵌套仓库。
- 修复子模块恢复需要从不同远端下载提交时，可能沿用错误代理的问题。
- 修复 Windows 上 Git 进程提前退出时，AI 提交消息可能无法生成的问题。
- 修复自定义命令快速运行时可能误触发停止，以及切换菜单时弹层可能误关或立即重开的问题。
- 修复工作树重命名事件传递和标签提交历史加载失败时的处理问题。
- 修复关闭目录已不存在的仓库时仍显示回收站选项的问题。
- 修复强制推送时关闭凭据窗口会误报失败并禁用推送按钮的问题。取消后可用原设置重新推送。
- 删除多个远程的标签、获取多个远程或批量丢弃修改时，取消认证会停止后续步骤。拉取或克隆后取消子模块认证时，会提示子模块操作未完成，并保留已完成的部分。

### 功能体验

- **多仓库切换**时保留旧画面，等目标仓库的数据就绪后再更新工作区和侧栏，减少闪烁。标签空间不足时，当前仓库保持可见，可从菜单搜索并用键盘切换其余仓库。
- **推送任务**会在切换仓库后继续运行，等待中的认证提示归属原仓库。对应仓库标签会显示推送进行中的状态。
- **扫描仓库**时可直接输入目录路径并按回车开始扫描。
- **提交详情的文件筛选**改为点击工具栏的搜索图标展开，适用于「差异文件」和「文件树」。收起筛选栏时保留当前条件。
- **搜索快捷键**会根据当前焦点打开对应的查找入口，适用于终端、编辑器、文件列表、提交列表和设置等区域。
- **终端会话**在收起面板后继续运行，关闭仓库后仍可操作已打开的 SSH 终端。终端选区支持右键复制，终端运行组件 `node-pty` 也已更新。
- **贮藏恢复**会保留上次应用失败的原因。再次查看时会重新检查当前工作区中阻挡恢复的路径。贮藏详情也会列出原先未跟踪的文件，可直接与工作区对比。
- **远程标签删除**统一对齐各远程的选项与结果，失败详情显示在对应远程下方。重试只处理尚未完成的远程。
- **AI 提交消息**增加可配置的生成超时时间。生成时优先使用指定语言，未配置时使用应用语言。提交按钮在生成或刷新状态期间保持文案稳定。
- **网络代理**改进应用请求的代理认证和 Git HTTPS 的远端匹配。提交作者的头像加载支持使用应用的代理设置。
- **文件审阅**统一未保存提示，改进窄面板中的文件路径与操作按钮布局，并在图片预览中合并显示尺寸与缩放比例。
- **界面交互**统一工具栏图标与列表选中样式，改进弹层之间的切换，以及表单行内错误提示。
- **深色主题**统一提亮文字按钮、链接和蓝色状态文字，改善更新日志、授权弹窗、命令输出和 SFTP 等界面的可读性。
- **打开入口**统一图标含义。子模块摘要中的「打开子模块」沿用「文件视图」的文字按钮样式，右键菜单使用子模块图标。冲突工具栏的「打开」使用下拉箭头，右上箭头表示在浏览器或外部程序中打开。
- **安装包**中的内置 Git 更新至 `2.56.1`，同时精简运行时依赖和 macOS 内置 Git 资源。
