相较 v1.1.1 的更新，截至 2026 年 10 月 28 日。

### 新功能

- **SSH 终端与服务器管理**：可集中保存和管理服务器配置，并从仓库终端连接已保存的服务器；支持交互输入、窗口尺寸调整、会话关闭和连接错误提示。
- **子模块历史与搜索**：历史提交中的子模块目录支持展开和搜索；已初始化的子模块也可纳入工作区文件索引与搜索。
- **更新日志区间预览**：可选择已发布版本的起止范围查看更新内容，并在加载失败后重试。
- **设置搜索**：可搜索设置项，快速找到提交身份、自定义命令等配置入口。

### Bug 修复

- 修复拉取仓库后自动更新子模块时，可能将已有本地改动的子模块切回父仓库记录的提交的问题。
- 修复子模块检出取消后仍可能启动 Git、重试时误操作其他子模块，以及通过符号链接路径检出的风险。
- 修复自动贮藏未成功创建时缺少明确提示，以及冲突处理重试、继续操作中可能出现的状态竞态。
- 修复 Git 历史图布局、提交选择和历史文件展示中的问题；改进特殊路径、忽略规则及仓库边界的处理。
- 修复安全存储解密失败时 AI Key 可能被误清空的问题，并在 AI 模型与服务器设置中提供重试或丢弃提示。
- 修复 Linux 多架构更新清单可能混入其他架构安装包的问题。
- 修复放大二进制图片预览时图片重新自适应、缩放比例或拖动边界不准确的问题。

### 功能体验

- **终端操作**：显示会话实际所在目录，支持搜索终端输出、重命名和重启会话，以及调整字体大小和行高；粘贴多行内容前增加确认，并完善终端标签固定和最大化交互。
- **子模块管理**：差异视图补充提交作者与版本来源，显示双方独有提交数量；检出时可限定所选子模块及其后代的范围，并保留已完成的检出结果。
- **AI 提交说明**：改进历史提交差异的读取与取消处理；遇到过大的补丁时改用摘要信息，降低界面卡顿和进程崩溃风险。
- **工作区搜索**：随应用提供搜索工具，减少安装依赖时对 GitHub 授权的要求。
- **编辑与审阅**：统一普通编辑器、合并视图和差异编辑器的字体；优化长提交信息、多选摘要及图片缩放指示器的展示。
